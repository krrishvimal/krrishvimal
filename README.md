## Featured Projects

### [Funnel Doctor AI](https://funneldoctorai.vercel.app/)
I built a checkout diagnostics prototype for direct-to-consumer (D2C) brands to help teams identify and investigate where shoppers abandon their purchases. 

**What the user can do:**  
Users can submit a live storefront checkout URL to scan the page for common checkout obstacles. The tool integrates Google Gemini to review mobile viewport screenshots and underlying page structure for possible causes of friction—such as non-numeric keyboards on phone number inputs, layout shifts, or confusing payment options.

**Testing & Data Clarifications:**  
- To evaluate the statistical analysis, I ran 1,000 simulated A/A tests to check how often the analysis flagged a difference between groups with the same underlying conversion rate.
- It applies the Benjamini–Hochberg procedure to address false discoveries when evaluating multiple comparisons.
- *Note:* Razorpay metrics in the prototype reflect test-mode results, and sample dashboard figures are illustrative simulations.

### [The Unsaid Desk](https://the-unsaid-desk.vercel.app/) · [Repository](https://github.com/krrishvimal/dear-stranger)
I built an anonymous letter-sharing app with a typewriter-style writing flow and a shared wall that updates in real time.

**What the user can do:**  
Visitors can compose an anonymous reflection using an interactive typewriter interface with tactile mechanical audio feedback, post it to a public community wall, and read letters submitted by global peers. New notes and reader reactions sync live across connected screens without requiring account creation or manual page refreshes.

### [Mehrang](https://www.mehrang.net/)
I built and launched a searchable storefront for a real textile client, covering seven product categories and a WhatsApp inquiry flow with prefilled item details.

**What the user can do:**  
Customers can browse fabric collections, filter products by seven distinct categories, and search the inventory to find specific textiles. When interested in an item, clicking the inquiry button opens WhatsApp with the product's title and SKU prefilled for direct merchant assistance.

**Case Study:**  
While auditing the storefront, I noticed inconsistent free-shipping threshold wording across different pages. As a proposed next step, I designed an A/B test concept to evaluate whether standardizing the free-shipping threshold messaging improves shopper clarity, tracking WhatsApp inquiry clicks to measure buyer intent.

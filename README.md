## Featured Projects

### [Funnel Doctor AI](https://funneldoctorai.vercel.app/)
I built Funnel Doctor AI as a checkout diagnostics prototype for direct-to-consumer (D2C) brands. It helps teams investigate where shoppers drop off during checkout and uses Google Gemini to review mobile screenshots and page structure for possible causes.

To evaluate the statistical analysis, I ran 1,000 simulated A/A tests to check how often the analysis flagged a difference between groups with the same underlying conversion rate. It also applies the Benjamini–Hochberg procedure to address false discoveries across multiple comparisons. In the live prototype, Razorpay metrics reflect test-mode results, and sample dashboard metrics are illustrative.

### [The Unsaid Desk](https://the-unsaid-desk.vercel.app/) · [Repository](https://github.com/krrishvimal/dear-stranger)
I built an anonymous letter-sharing app with a typewriter-style writing flow and a shared wall that updates in real time.

I designed the interface around a deliberate typing experience to encourage thoughtful reflection, added audio feedback, and structured the database with real-time updates so new notes appear without a page refresh.

### [Mehrang](https://www.mehrang.net/)
I built and launched a searchable storefront for Mehrang, a textile brand, covering seven product categories with a WhatsApp inquiry flow that prefills item details.

The site organizes fabric collections with category-level filtering and search to help buyers navigate inventory. As a proposed next step, I designed an A/B test to see whether consistent free-shipping wording helps shoppers understand the threshold, tracking WhatsApp inquiry clicks to evaluate the impact.
